# 🎬 Cinema Management System — Java

A refactoring project based on my second-year Computer Science group project (2025–2026). This repository documents the evolution of the original console application into a JavaFX application with database integration and improved architecture.

## 🛠️ Technologies

* Java
* JavaFX
* MySQL
* JDBC

## 👩🏻‍💻 Original Project

The original application was developed as a group project. I was responsible for much of the core system and its integration, including the `Cinema`, `Movie`, `Room`, `Ticket`, `VIPTicket`, and `Main` classes, as well as the main menu flow and authentication system.

## 🧠 Development Approach

Both the original project and this refactor are my own code. I use AI as a supporting tool to help locate relevant documentation and code references, understand errors, and identify where problems may be occurring during debugging. The implementation, code structure, and refactoring decisions are my own.

This refactor applies concepts I've learned since the original implementation to improve the application's structure, maintainability, and functionality.

*Further versions will introduce additional features and improvements as development continues.*


## 📦 Version History

### Version 1.0 — Management System

* Replaced the console interface with a JavaFX GUI.
* Implemented manager account management and authentication.
* Added cinema, room, and movie management.
* Integrated MySQL using JDBC for persistent data storage.
* Improved class organization and separation of responsibilities.

### Version 1.1 — Screening Management *(In Progress)*

* Add, search, update, and delete screenings.
* Schedule movies by room, date, time, and price.
* Enforce unique room schedules using database constraints.
